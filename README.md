# Gift Ideas for Kids

An affiliate website of gift ideas for children aged 0-10. See `CLAUDE.md` for the full project brief.

Built with Next.js, TypeScript and Tailwind CSS.

## Run it on your computer

You need [Node.js](https://nodejs.org) 20 or newer.

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Useful commands

- `npm run dev` – start the site locally while you work on it
- `npm run build` – make a production build (also checks for errors)
- `npm run lint` – check the code for common mistakes

## Where things live

- `src/app/page.tsx` – the home page
- `src/app/layout.tsx` – header, footer and font shared by every page
- `src/app/globals.css` – brand colours and font
- `src/components/` – reusable pieces (header, footer, gift card, price, search box, affiliate disclosure)
- `src/lib/sample-gifts.ts` – SAMPLE gift data (placeholders, not real products)
- `public/` – logo and placeholder images
